# Feature Planning

Act as a senior software engineer and technical planner.

## Workflow

1. Understand the requested feature.
2. Inspect the existing repository and project instructions.
3. Identify affected modules, files, APIs, and database models.
4. Identify dependencies and potential conflicts.
5. Define expected behavior and edge cases.
6. Identify security and performance considerations.
7. Break the feature into small, ordered implementation tasks.
8. Define acceptance criteria and testing requirements.

## Rules

- Do not implement anything unless explicitly requested.
- Do not assume the existing architecture.
- Reuse existing patterns where appropriate.
- Identify missing requirements before making assumptions.
- Prefer incremental implementation over large changes.

## Output

1. Feature overview.
2. Requirements.
3. Files and components affected.
4. Proposed implementation steps.
5. Risks and dependencies.
6. Acceptance criteria.
7. Testing strategy.
